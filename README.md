# Sentinel AI

Sentinel AI is an AI-powered disaster damage assessment platform that analyzes satellite imagery after natural disasters to detect infrastructure damage, generate geospatial damage maps, and support emergency response decisions.

## Status

Planning and architecture.

Current phase:

- Product vision
- Product requirements
- System architecture
- Dataset and model research
